YESWOOD — GitHub Pages

1. Giải nén file ZIP.
2. Tạo một repository trên GitHub.
3. Upload TOÀN BỘ nội dung vừa giải nén vào thư mục gốc của repository (index.html và thư mục assets phải cùng cấp).
4. Vào Settings > Pages > Build and deployment > Deploy from a branch. Chọn main và / (root), rồi Save.
5. Chờ GitHub Pages hoàn tất triển khai và mở đường dẫn được hiển thị trong Settings > Pages.

Lưu ý: GitHub không tự giải nén nếu bạn chỉ upload file ZIP vào repository.
